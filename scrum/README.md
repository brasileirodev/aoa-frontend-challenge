# Scrum Planning

This folder documents the planning process for the AOA frontend challenge.

The goal is to make the remaining work clear and estimable. Each feature has one
user story file with a clear deliverable scope.

## Structure

- `user-stories/`: feature-level user stories.

## Planning Rules

- Keep each story large enough to represent a useful delivery step.
- Keep each story small enough to complete within a short challenge timeline.
- Define user value before implementation details.
- Use acceptance criteria to decide when the feature is done.
- Keep technical limits explicit when they affect the deliverable.
