# **Registration Form**

## _Senior Frontend Engineer_

You are a Senior Frontend Engineer at AOA. We are launching a new B2B SaaS application that allows businesses to select a plan, register, and pay. Your task is to build that multi-step registration form for new accounts in short time.

### **Technical Requirements**

You are provided with a basic Next.js starter repository containing a Tailwind CSS configuration written entirely with AI. Please adhere to the following requirements:

- **Framework:** Next.js (App Router preferred)
- **Language:** TypeScript
- **Styling:** Tailwind CSS

### **Task**

1. Build a registration form for a modern eCommerce storefront using Next.js and TypeScript.
   - Please make assumptions and document those assumptions in the README.md (see below),
2. Identify and/or correct any glaring issues with the AI-generated starter repository.

### **Deliverables**

Please submit your completion by email with the following:

1. **Repository:** A private GitHub repository link.
2. **Live Demo:** A deployed URL (e.g., Vercel or Netlify) showcasing the working registration form.
3. **Brief Documentation:** A `README.md` explaining your architectural decisions and any trade-offs you made and any elements you left out for the sake of time.
4. **Intake Questions**: if this were an actual project and an actual task, a list of questions you would require to have answers to before beginning, and a list of desired questions you would request to have answers to before beginning.
